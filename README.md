# EverBooks 📚

EverBooks es un sitio web de venta de libros y accesorios para lectores (marcapáginas, anillos lectores, ediciones especiales), desarrollado como proyecto final del curso de HTML/CSS/Sass de CoderHouse.

El objetivo del proyecto es aplicar maquetación responsiva con Bootstrap, arquitectura modular en Sass (variables, mixins con parámetros, `@extend` con placeholders, partials organizados por carpetas y `@use`) y buenas prácticas de SEO local.

## 🔗 Demo en vivo

[Ver sitio desplegado](https://everbooks-nozetto-aldana.netlify.app)

## 🛠️ Tecnologías utilizadas

- HTML5 semántico
- Sass (SCSS) con arquitectura modular (`base/`, `components/`, `layout/`, `utilities/`)
- Bootstrap 5 (grid responsivo, navbar con menú hamburguesa, carrusel)
- AOS (Animate On Scroll)
- Git / GitHub

## 📄 Páginas

- **Inicio**: presentación del sitio, box literarios destacados y carrusel de accesorios.
- **Libros**: catálogo de libros, combos y ediciones especiales.
- **Varieté Lector**: accesorios como marcapáginas y anillos lectores.
- **Sobre Nosotros**: historia del emprendimiento.
- **Contactos**: medios de contacto y redes sociales.
